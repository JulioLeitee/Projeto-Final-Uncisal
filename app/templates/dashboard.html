OWASP Top 10:2025 — controles implementados

  • A01
    Broken Access Control

    Rotas internas exigem sessão validada no servidor; logout só por POST com token CSRF.

    app/security.py
  • A02
    Security Misconfiguration

    Não inicia sem chave secreta; cookie Secure, HttpOnly e SameSite; CSP restritiva e demais cabeçalhos de segurança.

    app/app.py app/security.py
  • A03
    Software Supply Chain Failures

    Dependências com versão fixa, auditadas com pip-audit a cada push e atualizadas via Dependabot.

    app/requirements.txt .github/workflows/deploy.yml
  • A05
    Injection

    Entradas validadas por lista de caracteres permitidos; templates com escape automático; logs sem quebra de linha.

    app/security.py
  • A07
    Authentication Failures

    Senhas com Argon2id; mensagem de erro genérica; bloqueio após 5 tentativas; nova sessão a cada login.

    app/auth.py app/app.py

Infraestrutura

  • TLS
    HTTPS com redirecionamento

    Todo acesso HTTP é redirecionado (301) para HTTPS; certificado Let's Encrypt emitido para o IP; HSTS ativo.

  • PQC
    Criptografia pós-quântica

    Troca de chaves híbrida X25519MLKEM768 negociada em TLS 1.3.

  • SSH
    Acesso remoto protegido

    SSH somente por chave, sem senha; Fail2Ban bane por 24 horas após 4 erros.
